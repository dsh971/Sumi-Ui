---
title: DropdownMenu
description: A Radix-based menu with items, checkboxes, radio groups, and submenus.
---

```tsx
import {
  DropdownMenu,
  DropdownMenuTrigger,
  DropdownMenuContent,
  DropdownMenuItem,
  DropdownMenuLabel,
  DropdownMenuSeparator,
} from "@sumiui/react";
```

## Props

`DropdownMenu`, `DropdownMenuTrigger`, `DropdownMenuContent`,
`DropdownMenuLabel`, `DropdownMenuSeparator`, `DropdownMenuCheckboxItem`,
`DropdownMenuRadioGroup`, `DropdownMenuRadioItem`, `DropdownMenuSub`,
`DropdownMenuSubTrigger`, and `DropdownMenuSubContent` mirror their Radix
UI `DropdownMenu.*` equivalents directly.

`DropdownMenuItem` extends Radix UI's `DropdownMenu.Item` props, plus:

| Prop | Type | Default |
|---|---|---|
| `inset` | `boolean` | `false` |
| `variant` | `"default" \| "danger"` | `"default"` |
