## Props

`Checkbox` extends Radix UI's `Checkbox.Root` props (`checked`, `defaultChecked`,
`onCheckedChange`, `disabled`, etc.), plus:

| Prop | Type | Default |
|---|---|---|
| `label` | `string` | — |
| `helperText` | `string` | — |
| `errorText` | `string` | — |

`checked` accepts `boolean \| "indeterminate"`. When `errorText` is set, it
replaces `helperText` and the input is marked `aria-invalid`.
