## Props

`Tabs` mirrors Radix UI's `Tabs.Root` props (`defaultValue`, `value`,
`onValueChange`, etc.). `TabsContent` mirrors `Tabs.Content` directly.

`TabsList` and `TabsTrigger` mirror their Radix UI equivalents. Tabs have one
look — an ink underline under the active label. For a compact segmented
switch, use [`SegmentedControl`](../forms/segmented-control). The
`variant` prop was removed in 3.0.0.
