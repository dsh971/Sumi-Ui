## Props

`TableHeader`, `TableBody`, `TableFooter`, `TableRow`, `TableCell`, and
`TableCaption` extend their native HTML table element attributes directly.

`Table` extends `React.HTMLAttributes<HTMLTableElement>`, plus:

| Prop | Type | Default |
|---|---|---|
| `striped` | `boolean` | `false` |
| `stickyHeader` | `boolean` | `false` |
| `density` | `"default" \| "dense"` | `"default"` |
| `selectable` | `boolean` | `false` |
| `selectedIds` | `string[]` | — |
| `rowIds` | `string[]` | — |
| `onSelectionChange` | `(ids: string[]) => void` | — |

`TableHead` adds `sortable`, `sortDirection` (`"asc" \| "desc" \| "none"`),
and `onSort`. `TableRow` adds an optional `rowId` (required when inside a
`selectable` table). Use `TableSelectHead`/`TableSelectCell` for the
select-all/per-row checkbox columns. With no rows in `TableBody`, an empty
state renders automatically.

## Virtualizing large datasets

`TableBody` accepts an optional `virtualize` prop for windowed rendering
of large row counts — only the visible rows (plus a small overscan) are
in the DOM at once:

| Prop | Type | Default |
|---|---|---|
| `virtualize.rows` | `T[]` | — |
| `virtualize.estimateRowHeight` | `number` | — |
| `virtualize.renderRow` | `(row: T, index: number) => React.ReactNode` | — |
| `virtualize.overscan` | `number` | `8` |

When `virtualize` is set, `children` is ignored — `renderRow` returns
that row's `<TableCell>` children directly (no `<TableRow>` wrapper; the
virtualized body supplies it). This is an **opt-in, structurally
different rendering path**, not a transparent upgrade: virtualized rows
use `display: flex` for windowing instead of native table layout, so
**columns must be fixed-width** (size each `<TableCell>` explicitly —
they no longer auto-size against the header's column widths), and
`role="rowgroup"`/`role="row"` are set explicitly on the body/rows to
restore the ARIA table semantics that the `display` override otherwise
drops in some browsers. When `virtualize` is omitted (the default),
rendering is unchanged — native table markup, the existing
children-based API.

```tsx
<Table>
  <TableHeader>
    <TableRow>
      <TableHead style={{ width: 240 }}>Name</TableHead>
      <TableHead style={{ width: 160 }}>Role</TableHead>
    </TableRow>
  </TableHeader>
  <TableBody
    virtualize={{
      rows: people, // 5,000+ rows
      estimateRowHeight: 45,
      renderRow: (person) => (
        <>
          <TableCell style={{ width: 240 }}>{person.name}</TableCell>
          <TableCell style={{ width: 160 }}>{person.role}</TableCell>
        </>
      ),
    }}
  />
</Table>
```
