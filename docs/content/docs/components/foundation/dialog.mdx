---
title: Dialog
description: A titled, focus-trapped modal built on Radix UI's Dialog primitive.
---

```tsx
import {
  Dialog,
  DialogTrigger,
  DialogContent,
  DialogHeader,
  DialogTitle,
  DialogDescription,
  DialogFooter,
  DialogClose,
} from "@sumiui/react";
```

## Props

`Dialog` and `DialogTrigger`/`DialogClose` mirror Radix UI's `Dialog.Root`/
`Dialog.Trigger`/`Dialog.Close` props directly (`open`, `defaultOpen`,
`onOpenChange`, `asChild`, etc.).

`DialogContent` extends Radix UI's `Dialog.Content` props, plus:

| Prop | Type | Default |
|---|---|---|
| `showClose` | `boolean` | `true` |

`DialogHeader` and `DialogFooter` are plain `<div>` layout wrappers.
`DialogTitle` and `DialogDescription` mirror their Radix UI equivalents and
carry the system's title/body typography.
