## Props

`Seal` extends `React.SVGAttributes<SVGElement>` (minus `color`), plus:

| Prop | Type | Default |
|---|---|---|
| `glyph` | `string` (Hanzi glyph inside the seal) | `"墨"` |
| `size` | `"sm" \| "md" \| "lg" \| "xl"` | `"md"` |
| `aria-label` | `string` | `"Sumi seal"` |
