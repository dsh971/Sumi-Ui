## Props

| Prop | Type | Default |
|---|---|---|
| `size` | `"sm" \| "md" \| "lg" \| "xl" \| "2xl" \| "read" \| "app"` | `"app"` |
| `gutter` | `boolean` | `true` |

`size="read"` maps to `--measure-read` (680px) for long-form prose;
`size="app"` maps to `--measure-app` (1200px) for app-shell layouts. The
rest map directly to the `--container-*` breakpoint tokens. Set
`gutter={false}` to drop the responsive side padding for edge-to-edge
content at the container's width.
