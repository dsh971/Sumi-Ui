## Props

| Prop | Type | Default |
|---|---|---|
| `value` | `string` (ISO `"YYYY-MM-DD"`) | — |
| `onChange` | `(value: string) => void` | — |
| `placeholder` | `string` | — |
| `disabled` | `boolean` | `false` |
| `label` | `string` | — |
| `helperText` | `string` | — |
| `errorText` | `string` | — |
| `min` | `string` (ISO `"YYYY-MM-DD"`) | — |
| `max` | `string` (ISO `"YYYY-MM-DD"`) | — |

When `errorText` is set, it replaces `helperText`.
