```tsx
import { Select, SelectContent, SelectItem } from "@sumiui/react";
```

## Props

`Select` extends Radix UI's `Select.Root` props, plus:

| Prop | Type |
|---|---|
| `label` | `string` |
| `helperText` | `string` |
| `errorText` | `string` |
| `placeholder` | `string` |
| `triggerClassName` | `string` |

`SelectContent`, `SelectItem`, `SelectGroup`, `SelectLabel`, and
`SelectSeparator` mirror their Radix UI equivalents directly.
