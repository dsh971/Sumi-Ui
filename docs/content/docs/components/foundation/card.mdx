title: Card

```tsx
import { Card, CardHeader, CardBody, CardFooter } from "@sumiui/react";
```

<ComponentDemo name="card/basic" />

## Props

| Prop | Type | Default |
|---|---|---|
| `variant` | `"default" \| "elevated"` | `"default"` |
| `asChild` | `boolean` | `false` |

`CardHeader`, `CardBody`, and `CardFooter` each accept every native `<div>`
attribute — they're layout-only, no required props.
