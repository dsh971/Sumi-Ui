## Props

`RadioGroup` extends Radix UI's `RadioGroup.Root` props (`value`,
`defaultValue`, `onValueChange`, `disabled`, `aria-label`, etc.).

`RadioItem` extends Radix UI's `RadioGroup.Item` props, plus:

| Prop | Type | Default |
|---|---|---|
| `label` | `string` | — |
