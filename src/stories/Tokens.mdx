## Spacing

4px base scale — negative space is a first-class element.

| Token | Value | Use |
|---|---|---|
| `--space-0` | 0 | — |
| `--space-1` | 4px | Icon gap, tight inline |
| `--space-2` | 8px | Input padding, chip gap |
| `--space-3` | 12px | Form element spacing |
| `--space-4` | 16px | Card padding (compact) |
| `--space-5` | 20px | Card padding (default) |
| `--space-6` | 24px | Section gap (tight) |
| `--space-7` | 32px | Section gap (default) |
| `--space-8` | 40px | Between unrelated blocks |
| `--space-9` | 56px | Page gutter (desktop) |
| `--space-10` | 72px | — |
| `--space-11` | 96px | — |
| `--space-12` | 128px | Hero vertical padding |

| Token | Value | Use |

| `--radius-0` | 0 | Sharp edges, tables |
| `--radius-1` | 2px | Tags, dense badges |
| `--radius-2` | 4px | Inputs, buttons |
| `--radius-3` | 6px | Cards (default) |
| `--radius-4` | 10px | Modals, popovers |
| `--radius-5` | 14px | Large cards |
| `--radius-full` | 999px | Avatars, pills, toggle thumbs |

|---|---|---|
