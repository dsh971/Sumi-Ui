## Props

`Avatar` extends `React.HTMLAttributes<HTMLSpanElement>`, plus:

| Prop | Type | Default |
|---|---|---|
| `size` | `"sm" \| "md" \| "lg" \| "xl"` | `"md"` |
| `src` | `string` | — |
| `alt` | `string` | — |
| `fallback` | `string` (1–2 character initials) | — |

If `src` is omitted, or the image fails to load, the avatar falls back to
`fallback` initials (or `"?"` with neither).

`AvatarSeal` extends `Avatar`'s props with a cinnabar seal badge overlaid
at bottom-right:

| Prop | Type | Default |
|---|---|---|
| `sealGlyph` | `string` | `"墨"` |

The badge is square (with a modest corner radius), not circular — this is
intentional, a literal reference to a Chinese chop/seal (印章), which is
historically square, never round. See
[`Seal`](/docs/components/brand/seal) for the standalone version and the
full design rationale.

**Use `AvatarSeal` once per page, never on more than one avatar at a
time.** The design system treats the cinnabar seal as the single fully
saturated mark on a surface — it's a signature/verification motif, not a
per-row decorator. Reach for a [`Badge`](/docs/components/foundation/badge)
or a status dot instead if you need a per-item indicator repeated across
a list of avatars.
