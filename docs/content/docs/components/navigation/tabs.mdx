## Props

`Tabs` mirrors Radix UI's `Tabs.Root` props (`defaultValue`, `value`,
`onValueChange`, etc.). `TabsContent` mirrors `Tabs.Content` directly.

`TabsList` and `TabsTrigger` extend their Radix UI equivalents, plus:

| Prop | Type | Default |
|---|---|---|
| `variant` | `"underline" \| "segmented"` | `"underline"` |

`"underline"` is the spec primary variant.
