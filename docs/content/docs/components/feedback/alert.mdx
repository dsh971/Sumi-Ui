## Props

| Prop | Type | Default |
|---|---|---|
| `variant` | `"info" \| "success" \| "warning" \| "danger"` | `"info"` |
| `title` | `string` | — |
| `onDismiss` | `() => void` | — |

`danger` uses an inverse cinnabar fill (dark `cinnabar-600` background,
`silk-50` text) with a lighter `cinnabar-200` left accent bar — the highest
severity level in the system.

Passing `onDismiss` renders a close button; the component itself doesn't
track visibility, so the caller owns showing/hiding the alert.
