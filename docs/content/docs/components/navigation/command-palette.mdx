## Props

`CommandPalette` is fully controlled — pass `open` and `onOpenChange`.

| Prop | Type | Default |
|---|---|---|
| `open` | `boolean` | — |
| `onOpenChange` | `(open: boolean) => void` | — |
| `groups` | `CommandGroup[]` | — |
| `onSelect` | `(item: CommandItem) => void` | — |
| `placeholder` | `string` | — |
| `emptyMessage` | `string` | — |

A `CommandItem` is `{ id, label, hint?, disabled? }`. A `CommandGroup` is
`{ label, items: CommandItem[] }`.
