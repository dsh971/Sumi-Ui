## Props

`Switch` extends Radix UI's `Switch.Root` props (`checked`, `defaultChecked`,
`onCheckedChange`, `disabled`, etc.), plus:

| Prop | Type | Default |
|---|---|---|
| `label` | `string` | — |
| `helperText` | `string` | — |
| `errorText` | `string` | — |

When `errorText` is set, it replaces `helperText`.
