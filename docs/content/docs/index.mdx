## sumi · 墨

**ink.** SumiUi is a React implementation of the Sumi Design System — a
calm, restrained, paper-and-ink UI library built around the discipline of
Chinese ink-wash painting. 30 fully-accessible components, Tailwind v4
tokens, dark mode, and TypeScript throughout.

## Looking for the component playground?

Every component also has a dedicated [Storybook](/Sumi-Ui/storybook/) for
exploring variants, states, and accessibility checks interactively — this
site is for guides and worked examples; Storybook is for poking at every
prop and state combination.
