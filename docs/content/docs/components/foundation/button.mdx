## Props

| Prop | Type | Default |
|---|---|---|
| `variant` | `"primary" \| "secondary" \| "ghost" \| "ink" \| "danger"` | `"primary"` |
| `size` | `"sm" \| "md" \| "lg"` | `"md"` |
| `loading` | `boolean` | `false` |
| `asChild` | `boolean` | `false` |

`Button` also accepts every native `<button>` attribute (`onClick`,
`disabled`, `type`, etc.).
