title: Toast
description: A Radix-based toast notification with success, info, warning, and danger variants.
---

```tsx
import {
  Toast,
  ToastProvider,
  ToastViewport,
  ToastTitle,
  ToastDescription,
  ToastAction,
  ToastClose,
} from "@sumiui/react";
```

## Props

`ToastProvider`, `ToastViewport`, `ToastTitle`, `ToastDescription`,
`ToastAction`, and `ToastClose` mirror their Radix UI `Toast.*`
equivalents directly.

`Toast` extends Radix UI's `Toast.Root` props (`open`, `onOpenChange`,
`duration`, etc.), plus:

| Prop | Type | Default |
|---|---|---|
| `variant` | `"success" \| "info" \| "warning" \| "danger"` | — |

`ToastViewport` is fixed-positioned to the page's top-right corner, so a
`Toast` must be triggered (via `open`/`onOpenChange`) rather than rendered
open by default.
