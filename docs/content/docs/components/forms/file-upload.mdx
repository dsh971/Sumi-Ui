## Props

| Prop | Type | Default |
|---|---|---|
| `accept` | `string` | — |
| `multiple` | `boolean` | `false` |
| `maxSize` | `number` (bytes) | — |
| `onFilesChange` | `(files: File[]) => void` | — |
| `disabled` | `boolean` | `false` |
| `label` | `string` | — |
| `helperText` | `string` | — |
| `errorText` | `string` | — |
| `files` | `File[]` (controlled file list) | — |

When `errorText` is set, it replaces `helperText`.
