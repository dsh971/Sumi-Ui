## Props

`Combobox` is fully controlled — pass `value` and `onValueChange`.

| Prop | Type | Default |
|---|---|---|
| `options` | `ComboboxOption[] \| ComboboxGroup[]` | — |
| `multiple` | `boolean` | `false` |
| `value` | `string` (single) or `string[]` (multiple) | — |
| `onValueChange` | `(value: string) => void` or `(value: string[]) => void` | — |
| `placeholder` | `string` | `"Search…"` |
| `label` | `string` | — |
| `loading` | `boolean` | `false` |
| `disabled` | `boolean` | `false` |

A `ComboboxOption` is `{ value, label, avatar?, subLabel? }`. A
`ComboboxGroup` is `{ label, options: ComboboxOption[] }`.

The option list is virtualized internally — passing hundreds or
thousands of options renders only the visible window, with the active
option auto-scrolled into view during keyboard navigation. This is
transparent: no extra props, no API change.
