## Props

| Prop | Type | Default |
|---|---|---|
| `variant` | `"neutral" \| "success" \| "warning" \| "danger" \| "info" \| "malachite" \| "canvas" \| "sienna" \| "seal"` | `"neutral"` |
| `dot` | `boolean` | `false` |

`Badge` also accepts every native `<span>` attribute.

`jade`, `clay`, and `peach` are deprecated aliases for `malachite`, `canvas`,
and `sienna` respectively — still fully supported, but new work should use
the canonical names.
