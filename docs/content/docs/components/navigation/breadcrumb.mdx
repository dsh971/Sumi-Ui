---
title: Breadcrumb
description: A path navigation trail with a custom or default separator.
---

```tsx
import {
  Breadcrumb,
  BreadcrumbList,
  BreadcrumbItem,
  BreadcrumbLink,
  BreadcrumbPage,
  BreadcrumbSeparator,
} from "@sumiui/react";
```

## Props

| Component | Notes |
|---|---|
| `Breadcrumb` | Renders a `<nav>` landmark; accepts `aria-label`. |
| `BreadcrumbList` | An `<ol>` wrapper. |
| `BreadcrumbItem` | An `<li>` wrapper. |
| `BreadcrumbLink` | An `<a>`; accepts `asChild` to render a custom element (e.g. a router `Link`). |
| `BreadcrumbPage` | The current, non-link page — renders a `<span>`. |
| `BreadcrumbSeparator` | Renders a default separator glyph, or custom `children`. |
