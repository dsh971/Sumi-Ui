## Props

`Input` extends every native `<input>` attribute except `size` (overridden
below), plus:

| Prop | Type | Default |
|---|---|---|
| `label` | `string` | — |
| `helperText` | `string` | — |
| `errorText` | `string` | — |
| `size` | `"sm" \| "md" \| "lg"` | `"md"` |

`TextArea` extends every native `<textarea>` attribute, plus the same
`label`/`helperText`/`errorText` props and a `rows` prop.

When `errorText` is set, it replaces `helperText` and the field is marked
`aria-invalid`.
