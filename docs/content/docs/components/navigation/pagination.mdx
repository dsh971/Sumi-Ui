## Props

`Pagination` is fully controlled — pass `page` and `onPageChange`.

| Prop | Type | Default |
|---|---|---|
| `page` | `number` (1-based) | — |
| `totalPages` | `number` | — |
| `onPageChange` | `(page: number) => void` | — |
| `siblingCount` | `number` | `1` |
