---
title: Timeline
description: An activity feed / event log, with optional nesting for trace-style views.
---

```tsx
import { Timeline } from "@sumiui/react";
```

## Props

| Prop | Type | Default |
|---|---|---|
| `items` | `TimelineItemData[]` | — |
| `timeGutter` | `boolean` | `true` |
| `selectedId` | `string` | — |
| `onItemClick` | `(item: TimelineItemData) => void` | — |
| `defaultCollapsedDepth` | `number` | — |

A `TimelineItemData` is:

| Field | Type |
|---|---|
| `id` | `string` |
| `time` | `string` |
| `title` | `ReactNode` |
| `description` | `string` |
| `marker` | `"dot" \| "dot-ok" \| "dot-info" \| "dot-warn" \| "dot-danger" \| "dot-pending" \| "dot-hollow" \| "icon" \| "icon-ok" \| "icon-danger"` |
| `iconNode` | `ReactNode` (used when `marker` is one of the `icon*` variants) |
| `avatar` | `{ initials: string, color: string }` |
| `groupLabel` | `string` |
| `children` | `TimelineItemData[]` — nest items to render a collapsible trace tree; pass `selectedId`/`onItemClick` to drive a master-detail view |
