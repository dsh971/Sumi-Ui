title: EmptyState

---

```tsx
import { EmptyState } from "@sumiui/react";
```

## Props

| Prop | Type | Notes |
|---|---|---|
| `title` | `string` | ≤ 6 words; optionally one italic-tinted word via `<accent-em>`. |
| `description` | `string` | ≤ 18 words of context. |
| `action` | `ReactNode` | Primary action button or link. |
| `closingBeat` | `string` | Short self-aware closing beat — "That's it." · "No fuss." |
| `icon` | `ReactNode` | Rendered at size 32 (e.g. a Lucide icon). |

The title renders in the display serif (`font-display`, Cormorant
Garamond) at 20px — intentional contrast against body text.
